# КУРСОВОЙ ПРОЕКТ
### Вариант 27А
# Постановка задачи
Составить программу, которая, согласно указанной формуле при разных значениях X, будет вычислять индикатор состояния системы освещения Q по показаниям датчика освещённости, контролировать отклонение Q от целевого значения Q₀ = 500 с границей Smax = 1000 и выводить состояние процесса (норма, предупреждение или тревога), а также вычислять среднее, дисперсию, среднеквадратичное отклонение и процент значений в диапазоне Q₀ ± 10 % из всех получившихся значений.
